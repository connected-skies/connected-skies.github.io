# Connected Skies

Website for the workshop **Smart Connected Cyber-Physical Systems — Paradigms, Threats and AI-based Solutions**,
20 October 2026, Department of Computer Science, University of Pisa (in collaboration with KAUST).

Live at <https://connected-skies.github.io>.

Plain static site (no build step): `index.html`, `style.css`, `script.js`.

- Registration form: https://forms.gle/5wG2kFB3YmLNoFA19 (linked from the three Register buttons in `index.html`).
- Talks: one `<article class="talk">` per talk in the `#talks` section of `index.html` (title, abstract, optional figure in `assets/talks/`, optional speaker bio).
- Programme: edit the `#programme` section in `index.html`.
- Local preview: `python3 -m http.server` and open <http://localhost:8000>.
